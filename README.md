# Laravel Recorder Logger

Componente Vue para gravação de tela com logging embutido. Instalável via Composer.

## Instalação

```bash
composer require seuuser/laravel-recorder-logger
php artisan vendor:publish --tag=recorder-components
```

## Uso

Importe o componente no seu Vue:

```js
import Recorder from '@/Components/RecorderLogger/Recorder.vue'
```
